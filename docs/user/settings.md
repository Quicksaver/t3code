# Provider and Magi settings

On wide web and desktop layouts, the provider list and selected provider's settings scroll
independently. Scroll inside the selected provider to reach lower controls, including favorite
models. On narrow layouts, the settings follow the list in the page's normal scroll flow.

Magi participant settings use the same layout. Each participant row shows its name and whether it
is included in new runs. Select a participant to read or edit its full instructions in the detail
pane.
